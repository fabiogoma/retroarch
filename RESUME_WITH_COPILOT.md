# Resume in GitHub Copilot

Open the repository checkout as the workspace. The original local installation
also contains ignored content and backups; these are not present in a fresh clone.

Paste this into Copilot Chat:

```text
Resume this ROM library / RetroArch Apple TV project. Read
.github/copilot-instructions.md, README.md, docs/OPERATIONS.md,
and docs/DOWNLOADS.md before making changes. COPILOT_HANDOFF.md is historical;
its ignored snapshot/state files may be available only in the original workspace.

Use the existing local files as context. Summarize the current state and
remaining on-device checks. Do not rebuild exports or upload anything merely
to restore context. Preserve the working Top 40 playlists, artwork, 60 Hz
audio setup, CRT shader, console bezels and original PS4 controller settings.
Then continue with my next request, checking current device state before
any remote changes.
```

The handoff is a snapshot from 21 November 2026. Later files or device changes take precedence after inspection. The snapshot records what was checked locally and what is based on earlier installation records or user feedback.
